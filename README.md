# Annie the Animator

Motion-design work for Broken Gear Industries. Private.

## Mascot (approved 2026-11-23)
A gear body with ONE tooth missing (the broken-gear idea from the BGI mark), gentle spin, level pill eyes. No face beyond the eyes.

- `mascot/Mascot_Emotions_v4.mp4` (latest): the same 24 emotions, each with its own small animation (symbols, particles, weather: sparkles, ?, !, steam, anger marks, tears, rain cloud, snot bubble, ha!, hearts, moon, radar rings). Source `mascot/mascot_emotions_v4.mjs`, overview `mascot/effects_sheet.png`.
- `mascot/Mascot_Emotions_v3.mp4`: 24 emotions in 57 s (calm, curious, focused, happy, excited, proud, surprised, confused, worried, sad, sleepy, bored, frustrated, angry, furious, relieved, mischievous, determined, embarrassed, overwhelmed, love, asleep, standby, "good one!").
- `mascot/mascot_emotions_v3.mjs`: the card source. Every emotion is a parameter set (eye shape, lids, tilt, look, body and eye colour, spin, shake, bounce, scale, glow) blended over 0.4 s, plus small one-shot animations. Renders with the Annie engine (1080x1920, 30 fps, silent).
- Stills: `emotions_sheet.png`, `new_emotions_sheet.png`, `proud_pair.png`.

The engine and the 36-skill tree live in the Reports folder on the CEO's Mac, not in this repo.
